# Who can decrypt the art in `public/oboro/mage/`. These are public keys and
# belong in the repo; the matching secret keys do not. `npm run art:keygen`
# appends the line for whoever runs it, so this is not hand-edited — one run per
# machine or person, then `npm run art:encrypt` so the sheets are readable to
# everyone listed.
#
# age has no default key location and never goes looking, so where the secret
# half lives is this project's choice: ~/.age/isometric-prototype.txt, which
# `npm run art:keygen` makes and which the other two commands then find on
# their own.
#
#   npm run art:keygen     # once — keeps any key already there, and lists it below
#   npm run art:encrypt    # after changing a sheet, or adding a recipient
#   npm run art:decrypt    # after a fresh clone
#
# CI gets the same key as the AGE_KEY secret, set once:
#
#   gh secret set AGE_KEY < ~/.age/isometric-prototype.txt
